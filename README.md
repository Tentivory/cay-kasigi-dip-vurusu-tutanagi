# Çay Kaşığı Dip Vuruşu Tutanak Dairesi

Bu depo bir yazılım değildir. Bu depo, ince belli bardağın dibine metal kaşığın vurduğu anı **kamu düzeni meselesi** sayan yan dairedir.

Kapı komşunun çayı çınladıysa, bu sorun değil, dosyadır.

## Neden var

Çünkü biri şekeri eritirken bardağa vurdu. Bir kez. Sonra bir kez daha. Üçüncü vuruşta cam rezonansa girdi, dördüncüde alt kattaki kedi sandalyeden indi, beşinicide daire başkanı (kayyum sıfatıyla) tutanak açtı.

Bilimsel dayanak: yok. Hukuki dayanak: kaşığın sesi. Ahlaki dayanak: çay sessiz içilir, dip dövülmez.

## Ne yapar

`cay_kasigi.py` gerçekten çalışır. Terminalden şunları sorar ya da argüman olarak alır:

- kaç kez dibe vuruldu
- şeker kaç küp
- komşunun kapı numarasi
- vuruş saati (gece 23'ten sonra ağırlaşır)

Sonra çınlama endeksi hesaplar, para cezasi uydurur, komşuya nota keser ve tutanağı ekrana basar. Bardak kırılmaz. Kaşık yargılanır.

## Kurulum

Python 3 yeter. Bağımlılık yoktur. Şeker ayrıca temin edilir.

```bash
python cay_kasigi.py
python cay_kasigi.py --vurus 9 --seker 2 --kapi 4B --saat 23:41
```

Çıktı bir tutanaktır. İmzalanmış sayılmaz. Yine de ciddidir.

## Sık sorulanlar

**Patates var mı?** Yok. Bu daire nişastayı tanımaz.

**Çay soğursa?** Dosya soğumaz. Çay soğur. İkisi farklı evrak türüdür.

**Kaşık tahta olursa?** Hafifletici sebep. Metal artırıcı sebeptir. Plastik kaşık usulsüzlük sayılır, ayrı dosya açılır, bu depoda yoktur.
